# StudySpace

Online Learning & Study Resources Management System.

## Project Overview

StudySpace is a web-based learning management system that allows students to browse courses, access study materials, and submit feedback. Administrators can manage courses, study materials, and user feedback.

## Main Features

- User registration, login and logout
- Role-based access for Admin and Students
- Course management (Create, Read, Update and Delete)
- Study materials management (Create, Read, Update and Delete)
- Course and study materials search
- Feedback submission and management

## Technologies Used

- Laravel 13
- PHP 8.3
- MySQL
- HTML, CSS and JavaScript
- Laragon
- Visual Studio Code

## Installation

1. Clone the repository.
2. Install dependencies using `composer install`.
3. Copy `.env.example` to `.env`.
4. Configure the database settings.
5. Generate the application key using `php artisan key:generate`.
6. Run migrations using `php artisan migrate`.
7. Start the server using `php artisan serve`.
